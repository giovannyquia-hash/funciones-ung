# Funciones · Universidad Nueva Granada

Página de práctica de Matemáticas Básicas con 28 competencias sobre:

- Evalúa funciones
- Escribir funciones a partir de ecuaciones
- Problemas verbales de notación de funciones
- Dominio y rango a partir de gráficas

## Uso local

Abre `index.html` en cualquier navegador. No requiere instalación ni servidor.

## Funcionalidades

- Buscador de competencias.
- Pregunta de ejemplo al pasar el cursor.
- Práctica con respuestas aleatorias y retroalimentación.
- Gráficas SVG para dominio y rango.
- Puntuación guardada en `localStorage`.
